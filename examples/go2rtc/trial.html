Direct camera playback trial

One go2rtc source shared by multiple viewers. This page requests media directly; it does not use the Node remux gateway.

Browser playback uses MP4 and needs browser-supported video and AAC audio; use each video's controls to unmute. Package playback uses MPEG-TS and provides the existing H.265 fallback, with audio disabled because this package does not yet bundle audio resources.

Start with one viewer. Multiple copies test sharing of one camera connection, not capacity for that many different cameras. Measure startup delay and steady-state latency against your existing WebRTC playback.

This local HTTP page is limited to four viewers to leave browser connections available for player assets. Use an HTTP/2 proxy for larger grids. If package startup stalls, reload the page to cancel pending loads.
